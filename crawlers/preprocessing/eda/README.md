# Thư Mục EDA (Exploratory Data Analysis)

Thư mục này được bố trí song song với `preClean` để phục vụ các bài toán phân tích khám phá dữ liệu sau khi dataset đã được sơ chế sạch sẽ.

## Nguồn Dữ Liệu Đầu Vào
- File dữ liệu đã làm sạch: `data/processed/preClean/merged_jobs_clean.json`

## Định Hướng Các Bài Phân Tích
1. **Phân tích Phân Bố Tiền Lương**:
   - Mức lương trung vị (Median) và trung bình theo cấp bậc (Junior, Mid, Senior, Lead).
   - So sánh mức lương giữa các nhóm công nghệ (AI/ML, Backend, Frontend, DevOps, Data).
2. **Top Kỹ Năng & Công Nghệ Được Săn Đón**:
   - Tần suất xuất hiện của các ngôn ngữ (Python, Java, Golang, TypeScript, C#...).
   - Xu hướng tuyển dụng theo tỉnh/thành phố (Hồ Chí Minh, Hà Nội, Đà Nẵng, Remote).
3. **Phân Tích Yêu Cầu Kinh Nghiệm & Học Vấn**.
