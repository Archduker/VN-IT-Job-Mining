# Việc Làm 24h Job Samples Overview

Thư mục này chứa 3 cặp file mẫu đại diện cho 3 cấu trúc bài đăng phổ biến trên Việc Làm 24h:

1. **`sample_standard_job.html` & `sample_standard_job.json`**:
   - Tin tuyển dụng tiêu chuẩn (mức lương số rõ ràng, mô tả và yêu cầu cơ bản).
   - Container selector: `div.job-detail-content`.

2. **`sample_hot_vip_job.html` & `sample_hot_vip_job.json`**:
   - Tin tuyển dụng Hot / VIP / Tuyển gấp có badge nổi bật và nhiều đãi ngộ mở rộng.
   - Container selector: `div.job-detail-content.vip-spotlight`.

3. **`sample_negotiable_salary.html` & `sample_negotiable_salary.json`**:
   - Tin tuyển dụng có mức lương "Thỏa thuận" hoặc nhiều thẻ kỹ năng chuyên môn.
   - Container selector: `div.job-detail-content.negotiable-salary`.
