# ⚠️ Nguồn này đã được thay thế

**JobsGO** đã bị loại khỏi danh sách nguồn thu thập vì:
- Cloudflare Turnstile chặn **toàn bộ** request tự động (HTTP 403)
- Ngay cả file `robots.txt` cũng bị chặn
- Headless Chrome cũng bị chặn bởi Cloudflare Challenge
- Cố bypass sẽ vi phạm quy tắc đạo đức dự án

**Khoa** đã chuyển sang phụ trách **VietnamWorks** (`sources/vietnamworks/`).
Xem chi tiết tại [TASKS.md](../../../TASKS.md).
