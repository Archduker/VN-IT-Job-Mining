# TopCV Job Samples Overview

Thư mục này chứa 3 cặp file mẫu đại diện cho 3 cấu trúc bài đăng phổ biến trên TopCV:

1. **`sample_standard_job.html` & `sample_standard_job.json`**:
   - Tin tuyển dụng tiêu chuẩn (lương VNĐ cố định, đầy đủ mô tả công việc và yêu cầu tuyển dụng).
   - Container selector: `div.job-detail__body`.

2. **`sample_hot_vip_job.html` & `sample_hot_vip_job.json`**:
   - Tin tuyển dụng VIP/Hot với badge nổi bật và quyền lợi mở rộng.
   - Container selector: `div.job-detail__information-detail`.

3. **`sample_negotiable_salary.html` & `sample_negotiable_salary.json`**:
   - Tin tuyển dụng có mức lương "Thỏa thuận", nhiều thẻ tags kỹ năng.
