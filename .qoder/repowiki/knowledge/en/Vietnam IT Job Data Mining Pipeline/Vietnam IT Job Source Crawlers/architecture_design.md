Each source under `sources/<name>/` is an independent package following the same three-file layout: `config.py` (constants only — base URL, listing paths, headers, delay/retry/checkpoint limits), `parser.py` (BeautifulSoup selectors producing a `raw` dict plus `validate_record`/`record_warnings` helpers), and `crawler.py` (HTTP client with random 2–5s delay + exponential backoff retry, checkpoint persistence, JSONL writer, and the top-level `crawl()` / `main()` entry point). The ITviec implementation is the only fully coded source; others are stub directories awaiting owners. Cross-cutting infrastructure (`common/http_client`, `checkpoint`, `jsonl_writer`, `schema`, `s3_uploader`, `telegram_notifier`) is planned but not yet in the repo — each crawler currently embeds local mock implementations so switching to `common/` later requires no logic changes. Output is partitioned as `data/<source>/dt=YYYY-MM-DD/batch_<seq>.jsonl` with `_meta` + `raw` records per TASKS.md §4.1, and raw HTML errors land in `data/<source>/errors/`. The module is invoked via `python run.py --source <name>` from the repo root.
