The repository is organized as a flat workspace where `crawlers/` holds independent per-source scrapers (ITviec, TopDev, CareerViet, VietnamWorks, TopCV, LinkedIn) that all emit a shared JSONL contract consumed downstream by the ELT pipeline. The top-level README documents the deployment flow: six contributors push crawler code to GitHub, a single operator pulls to EC2, cron runs the crawlers in batch, results land in S3 Raw → Staging → Curated zones, and Telegram reports status. `.env.example` centralizes the shared secrets (AWS credentials + Telegram bot token) that every child module reads at runtime. `docs/` provides the authoritative architecture guide and setup instructions that both crawlers and the ELT layer follow.
