This leaf module is a documentation-only scope with no source code. It contains five Markdown files that together describe the VN-IT-Job-Mining project: `data_mining_pipeline_and_architecture.md` defines the Modern Data Lakehouse + ELT (Raw → Staging → Curated on S3) architecture with a Mermaid flowchart and the daily rotating batch schedule across six crawlers; `ec2_s3_setup_guide.md` provides step-by-step instructions for provisioning an Ubuntu EC2 t2.micro, IAM user, S3 bucket (`vn-it-job-mining-data-lake-thuan`), `.env` credentials, and cron entries running `run.py --source <platform>` nightly; `merge.md` is a reconciliation memo between two earlier drafts (`vietnam_it_recruitment_data_mining_project.md` and `kien_truc_co_the.md`) listing five conflicts (schema, S3 partitioning, cadence, source list, timeline) with recommended resolutions; the remaining two files are the original academic brief and technical design being merged. Dependency direction is one-way: these docs reference the live repo structure (`crawlers/common/`, `etl/weekly_sync.py`, `run.py`) but nothing here imports them.
