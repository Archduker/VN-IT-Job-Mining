The setup guide prescribes SSH into EC2 via `ssh -i ec2-crawler-key.pem ubuntu@<IP>`, then `git clone https://github.com/Archduker/VN-IT-Job-Mining.git`, create a venv, install `requests beautifulsoup4 boto3 python-dotenv`, write `.env` with `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY`/`AWS_REGION=ap-southeast-1`/`S3_BUCKET=vn-it-job-mining-data-lake-thuan`, and configure crontab entries that run `python run.py --source <topdev|vietnamworks|careerviet|itviec|...> --max-items 450` at 21:00 each weekday plus a Sunday ELT sync.
