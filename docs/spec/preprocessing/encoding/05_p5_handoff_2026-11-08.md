# Bàn giao P5 — Feature Encoding & Matrices

> **Ghi chú 10/11/2026:** JEV, OpenJev và Qwen đã bỏ; cột xác suất `*_prob` không còn. Cờ thay thế: `it_rule_level`, `seniority_can_kiem`, `job_family_can_kiem` (xem `docs/spec/preprocessing/spec/P5_encoding.md`).

Đây là **điểm bắt đầu hiện hành** cho người tiếp nhận P5 của Phát. Tên file được giữ để các liên kết cũ tiếp tục hoạt động. Các ghi chép trước refactor được giữ nguyên tại [handoff lịch sử](05_p5_handoff_history_2026-11-09.md).

## 1. Bộ nào đang được bàn giao?

Nguồn xác định run là [artifact manifest canonical](../../../data/preprocessing/05_encoding/artifact_manifest.json), được đối chiếu với file thực tế; không chọn run theo thứ tự tên thư mục. Hiện hành: **p5_2026-11-09_cohort_v1**.

- P4: **5.177 job** → **5.104 include + 62 exclude + 11 quarantine**.
- X: **5.104 × 230**, vocabulary và thứ tự giữ nguyên; không có zero-column.
- Features: **5.104 × 314**; Golden: **5.104 × 292**; C: **230 × 230 int64**; TF-IDF: **5.104 × 3.000 CSR float32**.
- Review có giới hạn: 85 ID; **5.092 retained_unreviewed** không phải verified IT. Không sửa upstream filter hoặc job_family.

Đọc [execution contract](06_p5_execution_contract.md) để biết policy/schema và [execution report](07_p5_execution_report.md) để xem số liệu, lịch sử thực thi và giới hạn nghiệm thu. Tài liệu này chỉ điều hướng, không định nghĩa lại policy.

## 3. Input và entrypoint thực tế

Input được runner đọc là [manifest snapshot](../../../reports/preprocessing/05_encoding/snapshot_audit_2026-11-08/manifest.json) và tám file `<source>.parquet` cùng thư mục. Loader suy source từ key trong manifest rồi kiểm SHA/rows/schema. Các key R2 `staging/<source>/preprocessing/04_normalization.parquet` là provenance của snapshot; lượt chạy offline không tự tải R2. Đường dẫn `data/preprocessing/04_normalization/all.parquet` trong task là input logic chuẩn, không phải file mà run bàn giao này đọc.

Runtime assets: [frozen vocabulary](../../../preprocessing/encoding/assets/frozen_vocabulary_v1.json), [stopwords](../../../preprocessing/encoding/assets/jd_stopwords_v1.json), [ledger](../../../preprocessing/encoding/assets/cohort_v1/ledger.csv), [ledger metadata](../../../preprocessing/encoding/assets/cohort_v1/ledger.meta.json) và [decision record](../../../preprocessing/encoding/assets/cohort_v1/decision_record.json). Lọc include trước mọi fit/aggregate.

Dùng Python dự án **3.14.4** cho đợt refactor này. Từ repo root, kiểm tra đầy đủ luồng vào mà không ghi output:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m preprocessing.encoding.execute \
  --input-manifest reports/preprocessing/05_encoding/snapshot_audit_2026-11-08/manifest.json \
  --vocabulary preprocessing/encoding/assets/frozen_vocabulary_v1.json \
  --stopwords preprocessing/encoding/assets/jd_stopwords_v1.json \
  --cohort-ledger preprocessing/encoding/assets/cohort_v1/ledger.csv \
  --decision-record preprocessing/encoding/assets/cohort_v1/decision_record.json \
  --output-root /tmp/p5-cohort-output \
  --evidence-root /tmp/p5-cohort-evidence \
  --history-root data/preprocessing/05_encoding_history/p5_2026-11-09_frozen_v2 \
  --dry-run
```

Để tái tạo kiểm chứng: dùng hai thư mục tạm mới/chưa có output, bỏ `--dry-run`; sau đó so logical data với canonical. Không dùng `--publish` lên canonical chỉ để kiểm tra refactor. Lệnh publish của lần bàn giao đã chạy được ghi ở report07, không phải lệnh ghi đè an toàn cho lần sau.

`run_encoding.py` delegate cùng runner khi đủ config; `--apply`/`--source` legacy bị chặn trước ghi. `run.py:run` cũng yêu cầu explicit config. Driver năm bước chưa truyền config này sẽ fail ở P5; không tự migrate driver hoặc P4.

## 4. Downstream đọc bộ output

| Đường dẫn giữ ổn định | Vai trò |
|---|---|
| [Golden](../../../data/curated/curated_flat_golden_jobs.parquet) | 62 thuộc tính P4 của included IDs + 230 skill bits |
| [features.parquet](../../../data/preprocessing/05_encoding/features.parquet) | Key + E1–E8; chọn X bằng dictionary.skill_columns |
| [skill_cooccurrence.parquet](../../../data/preprocessing/05_encoding/skill_cooccurrence.parquet) | Counts int64, labelled index/columns cùng order X |
| [encoding_dictionary.json](../../../data/preprocessing/05_encoding/encoding_dictionary.json) | Mapping/order, top10, cohort counts, audit/predictor selectors |

Giữ cả `tfidf_matrix.npz`, `tfidf_rows.parquet`, `tfidf_vocabulary.json`, `tfidf_config.json`, `skill_unmatched.parquet`, `data_quality.parquet`, `validation_report.json`, `artifact_manifest.json` trong `data/preprocessing/05_encoding/`. Đây là sidecars cần cho alignment, tái lập và kiểm toán; không phải file tạm để xóa.

FP-Growth đọc X binary; C phục vụ graph, không thay transaction matrix. Clustering ghép TF-IDF theo `tfidf_rows.job_id_global`. RF/SHAP chọn target/cohort, bỏ audit/target-derived predictors và fit preprocessing train-only. Không coi job_family nguồn là gold label.

## 5. EDA và kiểm chứng

[Notebook hiện hành](../../../notebooks/eda_p5_final_cohort.ipynb) và [HTML](../../../notebooks/eda_p5_final_cohort.html) đọc manifest để chọn run. Notebook tự tìm repo root từ cwd/ancestors rồi thêm root vào sys.path; mở từ repo hoặc `notebooks/`, Restart Kernel → Run All. `covered` được tính trước khi dùng trong so sánh.

Tái tạo bằng kernel mới vào thư mục tạm: xem [hướng dẫn notebook](../../../notebooks/README.md). Giữ nguyên EDA cũ của 5.177 job.

Chạy P5 tests bằng `pytest` trên `tests/unit/test_encoding_*.py` và `tests/unit/test_vocabulary_comparison.py`; Ruff trên `preprocessing/encoding/` và các tests đó. [Report07, phần refactor](07_p5_execution_report.md#p5-refactor) ghi kết quả thực tế, file di chuyển/hợp nhất, những file phải giữ và những kiểm tra chưa xác minh.

Không tự thay trạng thái nghiệm thu: Python 3.12 vẫn chưa được kiểm chứng theo SPEC; toàn repo có lỗi collection ngoài P5. Lineage upstream và scope review chưa toàn diện vẫn là giới hạn công khai.
