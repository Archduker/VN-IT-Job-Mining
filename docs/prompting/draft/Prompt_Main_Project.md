# Mục tiêu nghiên cưu của dự án:

VN-IT-JOB mục tiêu nghiên cứu là nghiên về  thị trường lao động  đặc biệt là về phân tích nghề nghiệp và phân tích kỹ năng trong IT

Điều cần xác định:

+ Nghề nghiệp ở đây là các nhóm ngành như: backend developer, frontend developer, devops devloper, AI engineer, data analyst, QA, QC, ... (và nhiều nhóm ngành khác). -> Phân theo loại (domain)  dev, data, tester, AI, ...

+ Kỹ năng bao gồm có các loại về: 

- kỹ năng mềm như là Tiếng anh, giải quyết vấn đề, làm việc nhóm, ... 

- Kỹ năng chuyên môn: ngôn ngữ lập trình (pyhon, go , js,ts, ...). Framework(node.js, angular, ...).  Công cụ như (claude code, )

Lưu ý ở đây phải đào xâu về 2 loại nghề nghiệp và kỹ năng nhưng có những thứ liên quan cũng phải ưu tiên như tiền lương theo kỹ nâng

-> Mục tiêu là phân tích nên phải đào sâu. nên đánh giá mức độ quan trọng cào dữ liệu > xử lý dữ liệu > xử lý dữ liệu.

Người sử dụng hướng đến là sinh viên it ở VN. Đây là bài đồ án của nhóm tui.
