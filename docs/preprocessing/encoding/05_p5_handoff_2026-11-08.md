## 2. Input thực tế và lệnh chạy

Input offline là [manifest snapshot](../../../reports/preprocessing/05_encoding/snapshot_audit_2026-11-08/manifest.json) cùng tám `<source>.parquet`. Loader kiểm SHA, rows, schema, source, unique IDs và giữ thứ tự. Key R2 `staging/<source>/preprocessing/04_normalization.parquet` chỉ là provenance; không tự tải hoặc sửa R2.

Assets: [frozen vocabulary](../../../preprocessing/encoding/assets/frozen_vocabulary_v1.json), [stopwords](../../../preprocessing/encoding/assets/jd_stopwords_v1.json), [ledger](../../../preprocessing/encoding/assets/cohort_v1/ledger.csv), [ledger metadata](../../../preprocessing/encoding/assets/cohort_v1/ledger.meta.json), [decision record](../../../preprocessing/encoding/assets/cohort_v1/decision_record.json). Lọc include **trước** mọi fit/aggregate. Reference counts của vocabulary thuộc snapshot 5.177; observed counts 5.104 lưu riêng.

Từ repo root, dùng Python dự án **3.14.4**. Chạy kiểm chứng vào hai thư mục tạm mới, không ghi canonical:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m preprocessing.encoding.execute \
  --input-manifest reports/preprocessing/05_encoding/snapshot_audit_2026-11-08/manifest.json \
  --vocabulary preprocessing/encoding/assets/frozen_vocabulary_v1.json \
  --stopwords preprocessing/encoding/assets/jd_stopwords_v1.json \
  --cohort-ledger preprocessing/encoding/assets/cohort_v1/ledger.csv \
  --decision-record preprocessing/encoding/assets/cohort_v1/decision_record.json \
  --output-root /tmp/p5-cohort-output \
  --evidence-root /tmp/p5-cohort-evidence \
  --history-root data/preprocessing/05_encoding_history/p5_2026-11-09_frozen_v2
```

Thêm `--dry-run` để không ghi dataset/manifest; vẫn fit để kiểm config. CLI `run_encoding.py` delegate cùng implementation; `--apply`/`--source` legacy bị chặn trước ghi. API `run.py:run` yêu cầu explicit config. Driver năm bước chưa cấp config sẽ fail ở P5; không ghi prototype. Không tự migrate P4/driver.

Lần bàn giao canonical đã chạy `--output-root data --publish` với evidence ID cohort_v1. Đây là lịch sử, không phải lệnh overwrite an toàn cho lượt sau. Publish cần stage/validate đầy đủ, history checksum khớp bộ đang thay, evidence ID mới và manifest ghi cuối. Không dùng publish để kiểm refactor.
